# Asset Classification Template

Format:

```md
| Key    | Source File | Dims     | Size  | Quality              | Classification  | Recommendation                   |
| ------ | ----------- | -------- | ----- | -------------------- | --------------- | -------------------------------- |
| `hero` | `hero.jpg`  | 926×1280 | 78 KB | provisional-whatsapp | Cover candidate | Replace with original, 9:16 crop |
```

## Classification Labels

| Label                  | Criteria                                              |
| ---------------------- | ----------------------------------------------------- |
| Cover candidate        | Best quality/composition for hero background or cover |
| Hero portrait          | Widest or most expressive secondary portrait          |
| Family                 | Group photo of family / parents — not a solo portrait |
| Gallery feature        | Top 1–2 gallery images                                |
| Gallery secondary      | Remaining gallery images                              |
| Venue/location         | Ceremony or reception venue                           |
| Thank-you/closing      | Closing section portrait                              |
| Decorative break       | Interlude — no people, faces, or text                 |
| Do not use prominently | Weak, blurry, or irrelevant                           |

## Quality Status Labels

| Status                  | Meaning                               |
| ----------------------- | ------------------------------------- |
| `production-ready`      | Original high-res, graded, deployable |
| `provisional-whatsapp`  | WhatsApp-compressed — preview only    |
| `temporary-placeholder` | Filler — must not reach production    |
| `missing`               | Key references a missing asset        |
