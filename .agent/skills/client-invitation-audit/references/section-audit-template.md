# Section Audit Template

For each section:

```md
### Section: <name>

| Aspect              | Current                                                                     | Assessment                                      |
| ------------------- | --------------------------------------------------------------------------- | ----------------------------------------------- |
| Content             | <payload summary>                                                           | good / missing / PENDIENTE / needs confirmation |
| Assets              | <images, quality>                                                           | whatsapp / provisional / production-ready       |
| Variant             | <current setting>                                                           | must add / already set / automatic              |
| Copy                | <Spanish excerpt>                                                           | good / needs refinement                         |
| Focal points        | <current>                                                                   | provisional / needs adjustment                  |
| What works          | <bullets>                                                                   | —                                               |
| What looks weak     | <bullets>                                                                   | —                                               |
| Fix type            | content / asset / focal point / copy / variant config / reusable theme SCSS | —                                               |
| Risk                | HIGH / MEDIUM / LOW                                                         | —                                               |
| Priority            | P0–P3                                                                       | —                                               |
| Proposed correction | <action>                                                                    | —                                               |
```

## Priority Definitions

| Priority | Meaning                    |
| -------- | -------------------------- |
| P0       | Automatic via theme switch |
| P1       | Blocks correctness         |
| P2       | Polish                     |
| P3       | Deferred                   |

## Risk Definitions

| Risk   | Meaning                       |
| ------ | ----------------------------- |
| HIGH   | Public wrong/unconfirmed data |
| MEDIUM | Works but incomplete          |
| LOW    | Cosmetic or auto-resolved     |
