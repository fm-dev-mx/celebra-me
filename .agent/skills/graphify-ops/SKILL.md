# Graphify Ops

Thin loader for the authoritative Graphify policy.

1. Read [`.agent/rules/graphify-ops.md`](../../rules/graphify-ops.md) and follow it exactly.
2. If the task is not in the rule’s **Recommended** or **Optional** matrix, stop — do not refresh,
   query, or read `graphify-out/`.
3. When Graphify is justified: `pnpm ops graphify-refresh`, then `pnpm ops graphify-views` if needed;
   prefer `graphify-out/operational/` over NL `graphify query` / `path`.
4. Corroborate every actionable claim with `rg` and live file reads. Graph findings are leads only.
5. Host or global Graphify skills never override this skill or `.agent/rules/graphify-ops.md`. See
   [`.agent/load-skills.md`](../../load-skills.md).
