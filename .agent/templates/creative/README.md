# Creative Templates — Celebra-me

Celebra-me-branded templates for invitation design work. They follow the brand brief in
[`briefs/celebra-me.md`](../../briefs/celebra-me.md).

| Template                    | Purpose                                                       |
| --------------------------- | ------------------------------------------------------------- |
| `design-reference-brief.md` | Task-scoped visual context and acceptance contract            |
| `creative-qa-report.md`     | Checklist and report for the creative acceptance gate reviews |

Social, reel, and image-generation pipelines are not part of this repository; do not add templates
for them here.
