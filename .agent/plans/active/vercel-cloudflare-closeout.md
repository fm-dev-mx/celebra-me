# Vercel to Cloudflare migration close-out

This plan closes the migration: Production cutover, Vercel retirement, Cloudinary retirement, legacy
and dead-code removal, and the evidence that no invitation, demo, guest or RSVP record broke. It
replaces the dates of the cutover, Vercel retirement and media-to-R2 phases in
`cloudflare-workers-migration.md` §7 and §14; that plan keeps the technical design (§7.1, §8, §13).

## 1. Task Contract

| Field              | Value                                                                                                                                                                                                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Objective          | Production served only by the `celebra-me` Worker; Vercel and Cloudinary deleted; zero legacy and zero dead code; every published invitation and demo unchanged within the visual threshold; guest and RSVP data provably intact.                                   |
| Operation mode     | `plan` for this file. Each step runs in its own session with the mode it names (`implement`, `release-ops`, `validate`).                                                                                                                                            |
| Authorized actions | None by this plan. Every commit, push, PR, merge, migration apply, Cloudflare, DNS, Vercel, GitHub-settings and Production action needs the owner's explicit authorization in the session that runs it.                                                             |
| Scope              | Repository code, config, scripts, workflows, docs, `.agent/` rules and skills; Cloudflare account (Workers, R2, Access, Cron Triggers); Vercel project; Cloudinary account; GitHub settings; Supabase Auth redirect URLs.                                           |
| Non-goals          | Database redesign; new product features; Namecheap PremiumDNS cancellation; Email Service (the contact form is removed instead).                                                                                                                                    |
| Stop conditions    | Any go/no-go item red at Fri 2026-10-16 23:59 (cutover falls back to Mon 2026-10-19 02:00); any data check that shrinks a count or changes a pre-existing row; any visual diff above threshold on a published invitation; a migration needed inside a pause window. |
